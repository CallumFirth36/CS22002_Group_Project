# CS22002_Group_Project
## Requirements ##
- Python3.10+
- Flask


## How to Run the Project
### 1. Open Codespaces

### 2. Install Dependencies ###
```bash
pip install flask flask-sqlalchemy werkzeug flask-restful
```

### 3. Navigate to the backend folder
```bash
cd backend
```
### 4. Run app.py
```bash
python app.py
```
